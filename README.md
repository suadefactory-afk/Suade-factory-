# Suade Shoes Website

A responsive starter storefront for **Suade Shoes**, featuring five colour options:
black, white, blue, pink and green.

## Preview

Open `index.html` in a browser to preview the website. The `assets/storefront-preview.jpg`
file shows the visual design concept.

## Files

- `index.html` — website structure and product content
- `style.css` — layout, colours and responsive styling
- `script.js` — colour filters, search, mobile menu and demo cart
- `assets/` — generated shoe images, hero image, preview and favicon

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No build tools or installation are needed.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `suade-shoes`.
2. Upload all files and the complete `assets` folder. Keep the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site. The website address will appear in the Pages settings.

## Customise before launch

- Change the sample price (`R399.99`) in `index.html` to your real prices.
- Replace the generated shoe pictures in `assets/` with your own product photographs when available.
- Update the contact email (`hello@example.com`) and add your real social media links.
- Add real size options, stock levels, delivery details and return policies.
- The cart is a front-end demonstration only. It does not process orders or payments.
  To accept real orders, connect a trusted e-commerce or payment service and configure it securely.
- Check that the product name, branding and images are appropriate for your business before publishing.

## Images

The starter shoe and storefront images were AI-generated for this website concept. They are illustrative
product visuals, not verified photographs of a particular manufacturer's shoe model.
